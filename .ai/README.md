# Sistema temporal de trabajo

Los documentos de `.ai/` son temporales. No sustituyen a `docs/`.

```text
tasks/      tarea activa
handoffs/   continuación entre sesiones
debug/      investigación temporal
decisions/  borradores antes de un ADR
```

Al cerrar:

- conocimiento permanente → `docs/`;
- decisión → ADR;
- error importante → `ERRORES-Y-SOLUCIONES`;
- estado → `ESTADO-DEL-PROYECTO`;
- temporal obsoleto → se elimina.
